<product_requirements>
The Pergaminos digitalización application is a multi-tenant, AI-driven document management platform. Its purpose is to streamline the processing, organization, and analysis of PDF documents for various companies and projects.

Core features implemented include:
-   **User, Company, and Project Management**: Admins can manage companies, projects with custom codes, and users with different roles (staff, client).
-   **AI-Powered PDF Processing**: Modules like PDF Manager IA allow users to rename, reorder, and extract pages from PDFs using natural language instructions.
-   **Multi-Tenancy and Client Access**: Client-role users were initially tied to a single company. This has been enhanced to allow clients to be assigned to either an entire corporation (granting access to all its companies) or a specific list of multiple companies.
-   **Document History and Auditing**: An audit trail () logs all PDF manipulation operations (rename, extract, reorder). This history includes batch download functionality via checkboxes.
-   **Project Lifecycle Management**: Projects can be activated or deactivated via a toggle on their card. A configurable history retention policy (3, 6, 12 months) is set per project.
-   **QA and AI Interaction**: The system includes a QA review process for AI-processed documents and a client-facing portal for asking AI questions about the documents, with links to download source files.
</product_requirements>
