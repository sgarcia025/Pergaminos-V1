The Pergaminos digitalización app manages clients and projects, providing AI-driven PDF processing and user management. Recent enhancements included: custom project IDs, multi-contact support for companies, dashboard date filters, client read-only access, admin password reset, and Spanish localization of AI outputs. A key focus was developing PDF Manager and PDF Manager IA por Página modules for semantic PDF renaming, reordering, and extraction using natural language, supporting multi-tenancy. A Manual de Uso with AI chat and PDF download was added. A configurable AI module manages OpenAI keys. The system needs to handle large files and image-based PDFs via OCR. Current work involved enabling a global OCR toggle, allowing users to select between Tesseract and GPT-4o Vision, which applies only if the PDF has no embedded text. Additionally, functionality to extract pages and create new PDFs from existing ones was implemented. The system now needs to store and manage the history of these reordered and extracted documents.
